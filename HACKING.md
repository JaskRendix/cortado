# HACKING Notes for Cortado

## Directory Layout

* `src/main/java`: Source code
  * `com/jcraft`: Copy of JCraft Jogg and Jorbis source code, plus modifications
  * `com/fluendo`: Source code written by Fluendo
    * `utils`: Utility classes used by jst, jheora, examples
    * `jst`: A Java port of the GStreamer 0.10 design
    * `jheora`: A Java implementation of the Theora video codec
    * `jkate`: A basic Java implementation of the Kate codec
    * `jtiger`: A basic Kate stream renderer (simple text/images)
    * `codecs`: Additional codecs (e.g., Smoke codec)
    * `plugin`: Plugins implementing/wrapping sources, decoders, and sinks
    * `player`: Core player pipelines and logic
* `src/main/resources`: Project resources (e.g., `plugins.ini`)
* `src/test/java`: Unit tests (JUnit 5) for core utilities and player logic
* `target`: Built classes, test reports, and packaged JAR files generated by Maven

---

## Build & Development

The project has been modernized to use **Maven**. Standard build and test tasks are handled through Maven lifecycle commands:

* **Compile the project:**
  ```bash
  mvn compile
```

* **Run unit tests:**
```bash
mvn test
```


* **Package into a JAR:**
```bash
mvn package
```

## Contributing Guidelines

* **Code Style:** Maintain clear formatting, proper encapsulation, and use standard Java libraries where appropriate.
* **Testing:** Add or update unit tests under `src/test/java` for any new utility logic or bug fixes.
