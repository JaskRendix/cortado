# Cortado: Java Ogg Media Pipeline

**Cortado** is a classic open-source Java media streaming engine originally developed by [Fluendo](http://www.fluendo.com/) and hosted by [Xiph.org](https://www.xiph.org/) (view the original repository on [Xiph GitLab](https://gitlab.xiph.org/xiph/cortado)). Historically, Cortado was widely known as a browser-based Java Applet capable of streaming Ogg media (Theora video, Vorbis audio, and Kate subtitles) directly inside web pages.

This repository represents a **complete modernization** of Cortado. All 2000s-era legacy applet code, obsolete build systems, and proprietary dependencies have been completely stripped out and refactored, transforming Cortado into a clean, standalone, standard-compliant Java media pipeline library built with **Apache Maven** and backed by a comprehensive **JUnit 5** test suite.

---

## What Has Been Modernized?

* **Applet Decoupling:** Removed the legacy browser applet wrapper (`Cortado.java`) and configuration entrypoints (`Configure`), allowing the core engine to operate entirely as a standalone media playback pipeline.
* **Standard Maven Layout:** Migrated the codebase from custom directory structures into the modern standard Maven structure (`src/main/java`, `src/main/resources`, and `src/test/java`).
* **Removal of Dead Tech (`sun.audio`):** Permanently purged `AudioSinkSA.java`, which relied on the proprietary, undocumented Java 1.1 `sun.audio` APIs completely removed in Java 9+. Playback now relies exclusively on the modern, high-quality `javax.sound.sampled` backend (`AudioSinkJ2.java`).
* **Build Modernization:** Replaced old Ant XML configuration files (`build.xml`) with a clean, standard `pom.xml` build specification.
* **Unit Testing Suite:** Added a robust JUnit 5 testing framework covering pipelines, duration scanners, and UI/status logic.

## Project Structure

```text
cortado-master/
├── .github/
│   └── workflows/
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/fluendo/
│   │   │       ├── codecs/         # Smoke codec implementations
│   │   │       ├── jheora/         # Theora video decoder
│   │   │       ├── jkate/          # Kate subtitle/text decoder
│   │   │       ├── jst/            # Custom Java Streaming (GStreamer-like core pipeline)
│   │   │       ├── jtiger/         # Tiger rendering engine
│   │   │       ├── player/         # Cortado pipeline wrapper & duration scanner
│   │   │       ├── plugin/         # Demuxers, sinks, and decoders (Ogg, Vorbis, Theora)
│   │   │       └── utils/          # Base64, memory, and debugging utilities
│   │   └── resources/
│   │       └── plugins.ini         # GStreamer-style element factory configuration
│   └── test/
│       ├── java/
│       │   └── com/fluendo/        # Comprehensive JUnit 5 test suites mirroring main packages
│       └── resources/
│           └── media/              # Test Ogg/Ogv/Oga media assets for automated tests
├── target/                         # Compiled output artifacts (generated by Maven)
└── pom.xml                         # Maven project configuration file
```

## Building and Testing the Project

To build the project, run tests, and package Cortado into a standalone JAR file, ensure you have **Java 17+** and **Apache Maven** installed.

### Run the Test Suite

```powershell
mvn test
```

### Build and Package

```powershell
mvn clean package
```

Upon a successful build, your compiled standalone library JAR will be available at:
`target/cortado-1.0.0-SNAPSHOT.jar`
